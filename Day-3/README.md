Day 3, focused on understanding Role-Based Prompting.
Role-Based Prompting is a technique where we assign Claude a specific role or persona, 
such as a Developer, Product Manager, HR Manager, Founder, or Marketer, before giving it a task. 
This provides the AI with additional context, perspective, and direction, helping it generate more focused, relevant, structured, and actionable responses. 
The project demonstrates the difference between a generic prompt and a role-based prompt, 
showing how the same AI can produce different results depending on the role assigned. Through this exercise,
I explored how role-based prompting can improve response quality, reduce unnecessary follow-ups, save time, 
and make AI tools more effective for different professional use cases.
